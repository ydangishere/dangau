# Dang Au

Public bilingual business website for software outsourcing, custom software development, AI development, AI agents, backend integrations and UI/UX design.

- English: https://ydangishere.github.io/dangau/
- Vietnamese: https://ydangishere.github.io/dangau/vi/
- 14 static HTML pages with SEO metadata, canonical and hreflang links
- sitemap.xml and robots.txt

GitHub Pages deployment is managed by `.github/workflows/pages.yml`.
